# 供应商质量报告智能审核工具

把供应商提供的质量证明书、检测报告或合格证上传进去，程序会自动提取内容、对照审核依据、列出问题，并生成可以下载的 Excel 问题清单。

所有报告和审核数据默认保存在自己的电脑上。

## 一、准备工作

只需要提前安装：

- [Python 3.11 或更高版本](https://www.python.org/downloads/)
- 可选：自己的 LLM、Embedding 和 OCR 服务

安装 Python 时，Windows 用户记得勾选 `Add Python to PATH`。

> 程序不会自动下载大型 AI 模型。没有配置 LLM 时，数值、单位和一致性等本地规则仍然可以运行；扫描件和图片需要 OCR 服务。

## 二、启动软件

### Windows

1. 下载并解压整个项目。
2. 双击 `start.bat`。
3. 第一次启动会自动安装依赖，时间稍长。
4. 浏览器会自动打开 `http://127.0.0.1:8501`。

停止软件：双击 `stop.bat`。

### macOS

1. 下载并解压整个项目。
2. 双击 `start_macos.command`。
3. 第一次启动会自动安装依赖并打开浏览器。
4. 保持 Terminal 窗口开启；按 `Control-C` 停止软件。

如果 macOS 提示没有执行权限，在 Terminal 中进入项目目录，执行一次：

```bash
chmod +x start_macos.command
```

## 三、第一次配置 AI 服务

打开顶部的“系统设置”，分别填写：

1. `LLM`：填写 OpenAI-compatible 或 Ollama/LM Studio 地址、模型名称和 API Key。
2. `Embedding`：填写向量服务地址、模型名称和真实向量维度。
3. `OCR`：填写 MinerU-compatible 服务地址、Backend 和语言。

常见的本机地址示例：

```text
http://127.0.0.1:1234
http://127.0.0.1:11434
```

只填端口地址即可，程序会自动补全 `/v1`。

配置完成后：

1. 点击“保存配置”。
2. 点击“一键测试全部服务”。
3. 确认 LLM、Embedding 和 OCR 的测试结果。

如果使用公网接口，需要先开启“允许公网服务”。开启后，文档内容可能发送到该外部服务。

## 四、导入审核依据

1. 打开“审核依据库”。
2. 选择类别：采购/技术要求、图纸、企业标准或标准规范。
3. 上传 PDF、DOCX、XLSX 或 TXT。
4. 点击“解析并加入依据库”。

审核依据只需导入一次，以后可以重复选择使用。

## 五、开始审核

1. 打开“开始审核”。
2. 选择审核模板。
3. 选择本次使用的审核依据。
4. 左侧上传供应商质量文件。
5. 如有临时采购要求或图纸，在右侧上传补充依据。
6. 点击“开始审核”。

页面会显示当前正在做什么，以及调用的是 OCR、Embedding、LLM 还是本地规则。长时间没有新进度时，也会显示等待提示。

审核 CUSTOMER 紧固件时，选择内置的“CUSTOMER 紧固件质量文件审核”模板。程序会按页检查扫描内容，保留 PDF 表格行关系，核对 `Sample/Pass`、标准值/实测值、WDC、COC 与 COI/MTR 完整性。LLM 只允许补充带原文件名、页码和原文证据的问题，无法在原页验证的结论会被丢弃。

## 六、查看结果

打开“审核记录”，可以：

- 查看问题等级和审核结论。
- 对照供应商原文与审核依据条款。
- 确认、驳回、整改或关闭问题。
- 下载 Excel 问题清单。

打开“供应商档案”，可以：

- 按页查看报告文字。
- 预览图片和 PDF 页面。
- 查看 OCR、索引和文件信息。
- 下载原始报告。

## 七、常见问题

### 双击启动后没有反应

确认已经安装 Python 3.11+。Windows 用户还要确认安装时勾选了 `Add Python to PATH`。

### 提示 LLM 连接失败

先在“系统设置”填写 LLM Base URL（例如 `http://127.0.0.1:8080/v1`），模型名称留空时会使用服务端当前加载的默认模型；若指定模型，名称需与服务端一致。

### 图片或扫描 PDF 无法审核

图片和扫描件没有文字层，需要先配置可用的 MinerU-compatible OCR 服务。

混合型 PDF（部分页面有文字、部分页面是扫描图）也会逐页检查。OCR 未连接时，空白扫描页会明确显示为“需人工复核”，不会被静默忽略。

### 向量测试提示维度不匹配

把“向量维度”改成服务实际返回的维度，然后重新保存和测试。不同维度的索引不会混用。

### 审核一直停在 LLM

页面会显示正在调用的模型和地址。首次加载本地模型可能较慢；如果等待提示持续增长，请检查模型服务是否仍在运行。

## 数据安全

- 数据库、上传文件、索引和日志默认保存在项目的 `data/` 与 `logs/` 目录。
- API Key 加密保存在本地，页面只显示掩码。
- Git 配置已经排除数据库、报告、索引、日志、密钥和虚拟环境，避免误上传业务资料。
